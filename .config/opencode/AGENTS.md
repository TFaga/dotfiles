# Agent instructions

These are common instructions for agents across all projects and scenarios

## General guidelines

- Never use the em dash "-". Use plain dash "-" instead
- When writing commit messages, NEVER auto-add your agent name as co-author
- When writing code, use spaces instead of tabs
- Cleanup any temporary files you create
- When making technical decisions, do not give much weight to development cost. Instead prefer quality, simplicity, robustness, scalability, and long term maintainability.
- If something clearly looks off or wrong, even if it is not directly related to what you are doing, try to get it fixed along the way.
- Apply that same high standard to engineering excellence: lint, test failures, and test flakiness.
